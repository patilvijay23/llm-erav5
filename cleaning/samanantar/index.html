01 · strategies

Eight Session 4 strategies applied to monolingual Indic text

The pipeline is adapted to IndicCorpV2's single text field. Status labels below reflect what the supplied audit manifest says actually ran.

Executed

Text normalization

01

NFC normalization plus removal of selected zero-width, bidi, BOM, replacement and other control characters while preserving Indic ZWNJ/ZWJ.

Observed: 3,404,748 rows changed under NFC; 216,390 joiners preserved.
Executed

Canonical record format

02

The run used monolingual mode with text as the canonical content field; there are no source/target fields.

Why: one stable schema keeps downstream hashing, rejection logging and provenance deterministic.
Executed

Quality filtering

03

Rejects empty text, extreme lengths and repeated-character runs; HTML markup and script mismatches are surfaced as review flags.

Observed: empty text was the dominant rejection reason at 4,999,999 flags.
Partial

Deduplication

04

Exact-text deduplication ran in the streaming pass. Near-duplicate MinHash/LSH was not executed and remains a separate merged-corpus job.

Observed: 159,940 exact-duplicate flags.
Executed

Language validation

05

Script validation ran and flagged rows whose text did not match the expected script. Language counts were recorded for the processed sample.

Observed: 1,176 script-mismatch review flags.
Executed

PII removal

06

Structured PII masking covered email addresses, phone numbers, IPv4 addresses and URLs.

Observed: 32,594 rows were flagged as containing structured PII, with 56,315 mask operations recorded.
Not executed

Decontamination

07

No held-out registry was supplied, so benchmark/evaluation contamination scanning was not executed.

Next: provide immutable held-out fingerprints before using the cleaned output for training/evaluation claims.
Executed

Scope statement

This is an executed audit of a 9,999,999-row sample of ai4bharat/IndicCorpV2 run in Google Colab. It is not a full-corpus result. The sample itself contains only Assamese and Bengali rows, even though the dataset configuration lists 11 languages.

Run status

Exact deduplication, normalization, heuristic quality filtering, script review and structured PII masking ran. Near-deduplication and held-out-set decontamination remain pending.
